wax

AI 코딩 도구를 바꿔도 일은 이어집니다.

wax는 Claude Code, Codex, Antigravity CLI, GitHub Copilot CLI, Grok Build, Gemini CLI에 기획 → 설계 → 구현 → 검토 → 보고 흐름을 더하는 플러그인입니다. 사람이 결정하는 자리는 사람에게 남기고, 단계마다 근거를 남깁니다.

설치 (한 번)

Node.js 22 이상이 필요합니다. 쓰는 도구마다 두 줄을 실행하면 그 뒤로 모든 프로젝트에서 wax를 쓸 수 있습니다.

# Claude Code
claude plugin marketplace add cafein-network/wax
claude plugin install wax@wax

# Codex
codex plugin marketplace add cafein-network/wax
codex plugin add wax@wax

# GitHub Copilot CLI
copilot plugin marketplace add cafein-network/wax
copilot plugin install wax@wax

# Gemini CLI
gemini extensions install https://github.com/cafein-network/wax

Antigravity CLI와 Grok Build는 프로젝트에 연결한 스킬을 씁니다. 저장소를 받은 뒤 프로젝트마다 한 번 연결합니다.

git clone https://github.com/cafein-network/wax
node wax/scripts/install-project.mjs --project "/path/to/your-project"

인터넷이 없는 컴퓨터에는 최신 릴리스의 ZIP을 받아 압축을 푼 폴더 경로를 cafein-network/wax 대신 씁니다(오프라인 설치).

무엇을 하나

  • 단계마다 완료 조건과 근거(검사 실행 기록)를 남깁니다.
  • 대시보드에서 목표를 정하고 계획을 확인하면, PM 루프가 단계별 작업자를 제안하거나 띄웁니다.
  • 실행 승인, 계획 확정, 병합처럼 사람이 정할 일은 사람에게 묻습니다.
  • 공개된 버전은 Ubuntu·macOS·Windows와 Node 22·24에서 검사를 통과한 것만 올립니다.

Switch AI coding tools without losing the work.

wax is a plugin that adds a plan → design → implement → review → report workflow to Claude Code, Codex, Antigravity CLI, GitHub Copilot CLI, Grok Build and Gemini CLI. Decisions that belong to a person stay with a person, and every stage leaves evidence.

Installation (once)

Node.js 22 or later is required. Run the two lines for each tool you use, and wax is available in every project from then on.

# Claude Code
claude plugin marketplace add cafein-network/wax
claude plugin install wax@wax

# Codex
codex plugin marketplace add cafein-network/wax
codex plugin add wax@wax

# GitHub Copilot CLI
copilot plugin marketplace add cafein-network/wax
copilot plugin install wax@wax

# Gemini CLI
gemini extensions install https://github.com/cafein-network/wax

Antigravity CLI and Grok Build use skills linked into the project. Download this repository, then link it once per project.

git clone https://github.com/cafein-network/wax
node wax/scripts/install-project.mjs --project "/path/to/your-project"

For a computer without internet access, download the ZIP from the latest release and use the extracted folder path in place of cafein-network/wax (offline install).

What it does

  • Each stage has completion rules and keeps evidence (recorded check runs).
  • Set a goal and confirm the plan in the dashboard, and the PM loop suggests or starts a worker for each stage.
  • Decisions that belong to a person, such as run approvals, plan confirmation and merging, go to a person.
  • Published versions are only those that pass checks on Ubuntu, macOS and Windows with Node 22 and 24.
